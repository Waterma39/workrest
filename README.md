# workrest
# 工作休息 (workrest) 🐟

一款輕量級的跨平台打工人工具，結合 **薪資計時器** 與 **資產追蹤管理** 功能。支援 Web 網頁版以及 Android 行動裝置（透過 HTML5/JS 構建與 Android Studio 打包）。

---

## 🚀 線上試用 & 下載 (Demo & Download)

* 🌐 **Web 網頁版**：[點此立即使用]([(https://wordrest-theta.vercel.app/)]) *(或填寫你的 Vercel 網址)*
* 📱 **Android APP 下載**：[下載 摸魚.apk](./摸魚.apk)

---

## ✨ 主要功能 (Features)

* ⏰ **薪資實時計時**：即時計算當前上班時間已賺取的薪資，摸魚更有感。
* 📊 **資產追蹤管理**：支援跨資產（股票、加密貨幣、法定貨幣）追蹤，整合動態資料與 Chart.js 視覺化圖表。
* 👁️ **隱私保護模式**：一鍵切換遮蔽敏感金額與財務資訊。
* 💾 **本地資料儲存**：無需註冊帳號，資料直接存在瀏覽器或裝置本地（localStorage）。
* 📱 **響應式設計**：完美適配電腦與手機螢幕展示。

---

## 🛠️ 技術棧 (Tech Stack)

* **前端框架**：HTML5 / CSS3 / JavaScript (ES6+)
* **圖表渲染**：Chart.js
* **打包框架**：Android Studio (WebView / APK)
